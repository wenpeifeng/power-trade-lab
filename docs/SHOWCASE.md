# 演示素材指南

高质量截图和短录屏能显著降低理解成本，但演示素材也是最容易泄露账号、凭证、教材和本机路径的地方。所有素材应使用全新的演示账号和脱敏演示库录制。

## 推荐素材清单

在 `docs/showcase/` 放置以下文件：

| 文件 | 内容 | 建议尺寸/时长 |
|---|---|---|
| `hero.webp` | 门户首页全景，用作 README 首屏 | 1600×900，WebP |
| `guided-learning.webp` | 引导学习与能力路径 | 1600×900，WebP |
| `book-studio.webp` | 教材工坊章节学习 | 1600×900，WebP |
| `simulation.webp` | 全流程仿真申报/出清/结算 | 1600×900，WebP |
| `data-assets.webp` | 数据资产采集、审核、时间线 | 1600×900，WebP |
| `overview.mp4` | 从门户到完成一次交易复盘 | 60–120 秒，1080p |
| `overview.gif` | README 内快速预览 | 15–30 秒，尽量小于 15MB |

素材加入后，可在 README 的“演示与截图”章节插入：

```md
![Power Trade Lab 门户](docs/showcase/hero.webp)

<video src="docs/showcase/overview.mp4" controls title="Power Trade Lab 功能演示"></video>
```

GitHub 对视频内嵌展示存在差异，建议同时在 GitHub Release、Bilibili 或其他合规视频平台发布演示，并在 README 放链接。

## 60–90 秒录屏脚本

1. 5 秒：门户和产品定位。
2. 12 秒：引导学习，展示今日任务、课程和即时检查。
3. 12 秒：教材工坊，展示 PDF/Word → Markdown → 章节学习。
4. 20 秒：创建单人仿真，填写分段申报，执行封盘与出清。
5. 12 秒：查看结算和策略复盘，跳转到薄弱知识点。
6. 12 秒：政策公告原文追踪与知识库混合检索。
7. 12 秒：数据资产增量采集、质量审核和时间线。
8. 5 秒：项目地址与 Star 提示。

不要在演示中长时间滚动文字；每个镜头只表达一个产品价值。

## 发布前隐私检查

- 使用 `demo` 等虚构账号，不出现真实姓名、头像、邮箱或手机号。
- 浏览器书签栏、下载目录、终端用户名和本机绝对路径全部隐藏。
- 不展示 `.env`、开发者控制台、Network 请求头、数据库或日志。
- 不展示和风天气 API Host、项目 ID、凭据 ID、余额或调用账单。
- 不展示 GLM/其他模型 Key，即使只露出一部分也不展示。
- 教材使用自有、开放许可或专门制作的演示文档。
- 政策与公告保留官方来源，但不要把无再分发权的附件打包进仓库。
- 仿真数据明确标注为教学合成或公开重构数据。
- 截图元数据和文件名不包含个人信息。

## 视觉建议

- 门户突出蓝紫色的“学习—数据—仿真”能力闭环。
- 学习中心使用轻盈、亲和的浅色体系。
- 仿真终端使用专业、高信息密度的交易工作台。
- 数据资产中心使用清晰的数据流与质量治理视觉，不与学习中心同质化。
- 每张截图只保留一个主要视觉焦点，并尽量使用同一窗口尺寸。
