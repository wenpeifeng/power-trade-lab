# Power Trade Lab · 本地启动指南

## 1. 环境要求

- Python 3.11 或 3.12
- Node.js 22.12+
- npm
- macOS / Linux；Windows 建议 WSL2

## 2. 启动与停止

```bash
cd /path/to/power-trade-lab
./script/sh/start-all.sh
```

启动后：

- Web：<http://127.0.0.1:5173>
- API 文档：<http://127.0.0.1:8000/docs>

停止：

```bash
./script/sh/status-all.sh
./script/sh/stop-all.sh
```

脚本使用 `.run/` 中的项目 PID 文件管理进程，不会按端口关闭其他程序；日志位于 `logs/`。第一次运行会创建 `backend/.venv` 并安装前后端依赖。项目当前不使用 Docker。

## 3. 第一次使用

1. 打开 Web 地址。
2. 在登录页注册一个普通用户。
3. 从门户进入学习中心或仿真交易。
4. 如需管理数据资产、触发采集和审核外部数据，再创建管理员。

```bash
backend/.venv/bin/python backend/scripts/create_admin.py
```

系统没有默认管理员，也没有跨部署共享的统一密码。个人本地部署通常只需要一个管理员；团队部署应给每名管理员创建独立账号。

## 4. 零配置可用范围

下列功能不要求第三方 API Key：

- 门户和本地用户账号
- 引导学习、自由刷题、错题本、考试备考
- 基础知识库和政策公告
- 模拟账户、行情、申报和单人全流程仿真
- PDF 基础文本降级解析

下列功能按需配置：

- AI：每个登录用户在系统里填写自己的 GLM 等 API Key。
- MinerU：部署者连接独立解析服务，用于复杂 PDF/Word。
- 和风天气：部署者使用自己的开发者账号；开源默认关闭。
- 生产部署：强密钥、真实域名、CORS、数据库和 HTTPS。

完整参数见 [docs/CONFIGURATION.md](docs/CONFIGURATION.md)。

## 5. 推荐体验路径

1. 在门户完成能力诊断。
2. 进入“引导学习”，完成一节课程和即时检查。
3. 在“教材工坊”导入一份你有权使用的电力行业文档。
4. 进入“仿真交易”，创建一个单人场景。
5. 阅读简报，填写申报，执行封盘、出清和结算。
6. 根据复盘结果回到课程或错题复习。
7. 管理员可在数据资产中心查看增量采集、质量审核和时间线。

## 6. 开源发布前

```bash
python3 scripts/open_source_check.py
```

确认 `.env`、数据库、教材、附件、原始数据、日志和本机凭证全部处于 Git 忽略状态。详细清单见 [docs/OPEN_SOURCE_RELEASE.md](docs/OPEN_SOURCE_RELEASE.md)。
