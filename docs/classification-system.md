# 电力知识库分类体系规范

> 基于国家发改委/能源局/中电联权威口径深度调研，覆盖整个电力行业现有+爬取+未来所有内容。

## 一、设计理念：多维交叉分类

电力市场内容天然是多维交叉的，单一分类树无法覆盖。采用**双层架构**：

```
主分类树（8章业务导航）     ← 一篇文档归属一个主分类
       +
多维标签（5个维度）          ← 同一篇文档可打多个维度标签
```

## 二、8章主分类树（数字编码，机器可处理）

| 章 | 名称 | 编码 | 覆盖范围 |
|---|---|---|---|
| 0 | 📊 总览与基础 | 01-04 | 行业概览/电改历程/术语/数据 |
| 1 | 📜 政策法规 | 11-16 | 法律→国务院→部委→区域→省级→交易机构（6级金字塔）|
| 2 | 🏢 市场主体 | 21-26 | 发电/电网/售电/用户/新型主体/运营机构（官方4+1）|
| 3 | 💱 交易品种 | 31-38 | 电能量/辅助服务/容量/输电权/绿权/需求响应/电力金融 |
| 4 | ⚙️ 产业链 | 41-46 | 发电技术/输电/配电/调度/计量/用电 |
| 5 | 💰 电价结算 | 51-56 | 输配/上网/销售/容量/结算/交叉补贴 |
| 6 | 🚀 新兴交叉 | 61-68 | 储能/虚拟电厂/综合能源/分布式/碳/算电/氢/数字化 |
| 7 | 🗺️ 区域省级 | 71-73 | 区域/省级/跨省跨区 |
| 8 | 🌍 国际比较 | 81-82 | 国际经验/转型比较 |

编码规则：1位=章，2位=节，3位=子节（如 `311` = 交易品种/电能量市场/中长期）

## 三、5个多维标签维度

每篇文档除主分类外，自动打上以下标签实现交叉检索：

| 维度 | 标识 | 取值示例 |
|---|---|---|
| 市场主体 | `entity` | 发电企业/电网/售电/用户/新型主体/运营机构 |
| 交易品种 | `product` | 中长期/现货/辅助服务/容量/绿电/绿证/碳/储能 |
| 时间尺度 | `timeframe` | 年度/季度/月度/日前/实时/平衡 |
| 政策层级 | `source_level` | 法律/国务院/部委/区域/省级/交易机构 |
| 地域 | `region` | 全国/省间/华北/华东/南方/西北... |

## 四、自动归类引擎

文档入库时**自动**完成分类，无需人工选：

1. **关键词规则匹配**：60+分类节点的关键词词库，加权打分
2. **多维标签提取**：5个维度自动提取
3. **已验证**：现货→312，绿电→134，储能→61，准确率达标

API：`POST /category/classify-preview`（预览不入库）

## 五、检索能力

| 方式 | API | 场景 |
|---|---|---|
| 分类树浏览 | `GET /category/tree` | 左侧目录导航 |
| 按分类检索 | `GET /category/docs?code=312` | 点"现货市场"看所有现货文档 |
| 按标签检索 | `GET /category/by-facet?facet=product&value=现货` | "所有现货相关文档"跨分类 |
| 语义检索 | `GET /knowledge/search?q=电价怎么算` | AI助手召回 |

## 六、设计原则（保证可扩展）

1. **官方口径优先**：主体用4+1法定分类，品种用统一市场体系四分法
2. **物理层与市场层分离**：技术运行(章4)与市场机制(章3)分离
3. **新型主体独立成章**：储能/虚拟电厂横跨发用电，独立归类
4. **政策双轴**：层级(纵)+地域(横)，支持"看广东所有规则"和"看现货所有省份"
5. **预留扩展位**：38电力金融/65碳/67氢/68AI/8国际，新内容有处可放
6. **数字编码机器友好**：爬虫自动归类、URL生成、数据库索引
