# 数据资产工具使用说明

Power Trade Lab · 电力交易演练台 随仓库发布的不是数据，而是**捞数据的工具**。下载者 clone 后自行用这些工具把公开/自有内容灌进自己的实例——每个人拉自己的数据，不存在再分发问题。

数据资产中心提供 **4 类共 11 个工具**：定时爬虫、即时抓取、批量导入、外部连接器。全部经 `/api/admin/*` 或 `/api/asset/*` 调用，均需管理员身份。

## 0. 前置：建管理员 + 登录

```bash
# 1) 启动项目
./script/sh/start-all.sh

# 2) 建一个管理员（交互式输入密码，只做一次）
backend/.venv/bin/python backend/scripts/create_admin.py

# 3) 浏览器打开 http://127.0.0.1:5173 用管理员账号登录
#    进「数据资产中心」即可点按钮用所有工具（推荐，免手敲 API）
```

命令行/API 用法（高级）：登录拿 cookie，后续请求带 cookie。

```bash
curl -c cookies.txt -X POST http://127.0.0.1:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"你的密码"}'
```

## 2. 爬虫触发（推荐主路径）

**页面用法**：数据资产中心 →「爬虫触发（分类型）」→ 点某张卡的「立即运行」。

**API 用法**：可用 source 名见下表。

```bash
# 跑单个源（例：国家能源局政策统计）
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/admin/crawler/run/nea_statistics

# 跑全部公开源
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/admin/crawler/run-all
```

可用 source：

| source | 抓什么 | 开箱即用 |
|---|---|---|
| `gov_policy` | 发改委/能源局/国务院政策 | ✅ |
| `nea_statistics` | 国家能源局公开统计 | ✅ |
| `nbs_energy` | 国家统计局月度能源生产 | ✅ |
| `gzpec_market` | 广州电力交易中心公开行情 | ✅ |
| `carbon_market` | 全国碳市场日行情 | ✅ |
| `coal_price` / `carbon_price` | 动力煤/碳价 | ✅ |
| `clearing_price` / `load_forecast` | 出清价/负荷 | ✅ |
| `standard_pdf` | 行业标准 PDF | ✅ |
| `zhihu_bilibili` | 知乎/B站学习素材 | ✅ |
| `exchange_center` | 广州/北京交易中心公告 | ⚠ 需 `backend/.venv/bin/playwright install chromium` |
| `qweather` | 和风气象 | ⚠ 需自己凭证、`QWEATHER_ENABLED=true` |

> 省级交易中心运营平台（pmos.*.sgcc.com.cn 等受保护系统）**不在爬虫内**，永不接入。其数据应通过官方开放平台 API 以合规主体身份获取。

## 3. cURL 快速抓取（粘贴一条 curl 就入库）

适合"我看到某篇政策/公告网页，想立刻收进来"。粘贴一条 curl 命令，系统自动解析 URL→抓取→提取正文→归档。

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/curl \
  -H "Content-Type: application/json" \
  -d '{
    "curl": "curl '\''https://www.nea.gov.cn/20231228/xxx/c.html'\''",
    "doc_type": "national_policy",
    "province": null,
    "tags": ["电价","现货"]
  }'
```

支持 HTML 页面（提取正文）和 PDF/Word（下载为附件）。`doc_type` 可填 `national_policy`/`regulation`/`exchange_info`/`industry_news`/`exam_info`/`public_data`。

> 合规：只抓公开且允许使用的内容，遵守 robots.txt 与转载声明。

## 4. 上传文件

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/upload \
  -F "file=@/path/to/教材.pdf" \
  -F "doc_type=industry_news"
```

PDF/Word 走 pdfplumber 解析（默认可用）；复杂版面/扫描件需开启 MinerU（见 README「教材与 PDF 解析依赖」）。

## 5. 手动录入

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/manual \
  -H "Content-Type: application/json" \
  -d '{
    "title":"某省现货市场运行规则（摘录）",
    "content":"正文……",
    "doc_type":"regulation",
    "province":"山西"
  }'
```

## 6. Excel/CSV 批量导入

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/spreadsheet \
  -F "file=@/path/to/questions.xlsx" \
  -F "target=question" \
  -F "doc_type=industry_news"
```

`target` 取 `doc`（文档）/`question`（题库）/`policy`（政策）。表头模板见 `data/sample/`（如有）或参考 `backend/app/knowledge/ingest.py` 的列映射。

## 7. API 直连（配置式拉取 JSON 接口）

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/api \
  -H "Content-Type: application/json" \
  -d '{
    "url":"https://example.com/api/data",
    "method":"GET",
    "headers":{"Authorization":"Bearer YOUR_TOKEN"},
    "data_type":"clearing",
    "json_path":"data.rows"
  }'
```

> ⚠ 自填的 `Authorization` token 只在你自己的部署里使用，**不要把含真实 token 的请求体提交进仓库**。

## 8. RSS 订阅

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/rss \
  -H "Content-Type: application/json" \
  -d '{"feed_url":"https://example.com/rss.xml"}'
```

## 9. 飞书导入（需飞书应用凭据）

需先在飞书开放平台建应用，把 `FEISHU_APP_ID`/`FEISHU_APP_SECRET` 填进 `backend/.env`（参考 `scripts/import_feishu_wiki.py`）。

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/asset/ingest/feishu \
  -H "Content-Type: application/json" \
  -d '{"doc_token":"wikcnXXXX","doc_type":"industry_news"}'
```

飞书 Base 同步走 `/ingest/feishu-base`，需 lark CLI 可用。

## 10. 和风天气连接器（默认关闭）

默认 `QWEATHER_ENABLED=false`。要用：在 `backend/.env` 填自己的和风 API Host + 凭证（见 README「和风天气」节），然后：

```bash
# 测连接
curl -b cookies.txt http://127.0.0.1:8000/api/asset/connectors/qweather/test
# 搜城市
curl -b cookies.txt 'http://127.0.0.1:8000/api/asset/connectors/qweather/locations?q=太原'
```

## 11. AI 生题（需用户 LLM Key）

每位用户在前端「AI 设置」填自己的 GLM 等 Key（BYOK，不入仓库）。管理员可基于政策生题：

```bash
curl -b cookies.txt -X POST http://127.0.0.1:8000/api/admin/ai/generate-from-policy \
  -H "Content-Type: application/json" \
  -d '{"policy_id":12,"count":5}'
```

## 12. 合规边界（所有工具通用）

- 只抓取/导入**公开且允许使用**的内容，遵守 robots.txt、频率与署名要求。
- **不绕过**登录、验证码、反爬或权限控制。
- 省级交易中心运营平台（pmos.*）受保护系统**不接入**任何工具。
- 真实市场成员数据必须由有权用户授权导入。
- 含真实 token/密钥的请求体**不要提交进仓库**。
